# T-Hub: Тезаурус-Хаб программного кода

> Революционная платформа для управления программными компонентами, основанная на принципах уникальности, дедупликации и централизованного реестра.

---

## Концепция

**T-Hub** — это решение проблемы дублирования кода в современной разработке ПО. Подобно тому, как Wikipedia упорядочила знания человечества, а Amazon — мировую торговлю, T-Hub стремится упорядочить программный код.

### Ключевая проблема

Современные магазины приложений (Google Play, App Store, npm, GitHub) содержат **миллионы приложений с 80-90% дублирующегося кода**. Это приводит к:

- ❌ Избыточному использованию хранилища
- ❌ Дублированию усилий разработчиков
- ❌ Несогласованности версий библиотек
- ❌ Проблемам безопасности
- ❌ Высокой сложности поддержки

### Решение T-Hub

✅ **Единый реестр уникальных компонентов** — каждый компонент существует в единственном экземпляре
✅ **Автоматическая дедупликация** — предотвращение повторов
✅ **Content-addressed storage** — компоненты идентифицируются по хешу содержимого
✅ **Умное разрешение зависимостей** — автоматическое построение графа зависимостей
✅ **Проверка качества** — автоматизированные проверки безопасности и качества кода

## Прототип

В директории `prototype/` находится работающий прототип T-Hub:

```
prototype/
├── package.json              # Зависимости проекта
├── cli/
│   └── index.js             # CLI интерфейс
├── core/
│   ├── deduplication.js     # Движок дедупликации
│   └── dependency-resolver.js  # Разрешение зависимостей
├── api/                      # REST API (будет добавлено)
└── examples/                 # Примеры использования
```

### Установка прототипа

```bash
cd prototype
npm install
npm link  # Для глобальной установки CLI
```

### Использование CLI

```bash
# Инициализация проекта
thub init

# Публикация компонента
thub publish ./my-component.js --name my-component --category utilities

# Поиск компонентов
thub search "jwt authentication"

# Установка компонента
thub install jwt-generator@2.1.3

# Информация о компоненте
thub info jwt-generator

# Сборка приложения
thub build

# Поиск дубликатов
thub deduplicate

# Статистика проекта
thub stats
```

## Ключевые возможности

### 🔍 Автоматическая дедупликация

**3 уровня обнаружения дубликатов:**

1. **Exact Match** — точное совпадение (SHA-256 hash)
2. **Normalized Match** — игнорирование форматирования
3. **Semantic Match** — семантическая схожесть кода

```javascript
const dedup = new DeduplicationEngine(registry);

// Проверка при публикации
const result = await dedup.registerComponent(component);

if (result.status === 'duplicate') {
  console.log('Компонент уже существует!');
}
```

### 📦 Умное разрешение зависимостей

```javascript
const resolver = new DependencyResolver(registry);

// Построение графа зависимостей
const graph = await resolver.buildDependencyGraph(component);

// Топологическая сортировка (порядок загрузки)
const buildOrder = resolver.topologicalSort(graph);

// Проверка безопасности обновления
const safety = await resolver.checkUpdateSafety('jwt-gen', '3.0.0');
```

### 🏗️ Декларативная сборка приложений


## Преимущества

### 💾 Экономия хранилища

```
Традиционный подход:
  1000 приложений × 10 MB = 10 GB

T-Hub подход:
  Общий код: 8 MB (единожды)
  Уникальный код: 2 GB
  Итого: 2 GB

Экономия: 80%
```

### ⚡ Ускорение развёртывания

```
Традиционный:
  Download: 10 MB
  Build: 30s
  Total: ~40s

T-Hub:
  Download: 2 MB (только уникальный код)
  Link shared: instant
  Build: 10s
  Total: ~12s

Ускорение: 3-4x
```

### 🔒 Быстрые обновления безопасности

```
Традиционный:
  Security patch → 1000 приложений
  Каждое нужно пересобрать
  Время: дни/недели

T-Hub:
  Security patch → 1 компонент
  Все приложения получают мгновенно
  Время: минуты
```

## Технологический стек

### Backend
- **API**: Node.js (Fastify/NestJS) или Go (Gin)
- **Database**: PostgreSQL + Redis
- **Storage**: S3-compatible (MinIO/AWS S3)
