# Определения и базовые концепции

## 1. Что такое программа?

**Программа** — это упорядоченная последовательность инструкций (код), предназначенная для выполнения компьютером определённых задач.

### Характеристики программы:
- **Исполняемость** — способность выполняться на целевой платформе
- **Алгоритмичность** — наличие чёткой последовательности действий
- **Детерминированность** — предсказуемость результата при одинаковых входных данных
- **Функциональность** — решение конкретных задач

### Типы программ:
1. **Системное ПО** — операционные системы, драйверы, утилиты
2. **Прикладное ПО** — приложения для конечных пользователей
3. **Инструментальное ПО** — средства разработки (компиляторы, IDE)
4. **Встроенное ПО** — firmware для специализированных устройств

---

## 2. Что такое приложение?

**Приложение (Application)** — программа, предназначенная для выполнения определённых пользовательских задач.

### Основные характеристики:
- **Пользовательский интерфейс** (UI/UX)
- **Бизнес-логика** — правила обработки данных
- **Управление данными** — хранение и обработка информации
- **Взаимодействие с системой** — использование ресурсов ОС

### Классификация по среде выполнения:
- **Desktop-приложения** — работают локально на компьютере
- **Mobile-приложения** — для смартфонов и планшетов
- **Web-приложения** — работают в браузере
- **Гибридные приложения** — сочетают несколько подходов

---

## 3. Что такое интернет-приложение (Web Application)?

**Интернет-приложение** — программное обеспечение, которое работает на удалённом сервере и доступно через сеть Интернет посредством веб-браузера или специализированного клиента.

### Архитектурные компоненты:

#### Frontend (Клиентская часть):
- **HTML** — структура контента
- **CSS** — визуальное оформление
- **JavaScript** — интерактивность и логика

#### Backend (Серверная часть):
- **Сервер приложений** — обработка запросов
- **База данных** — хранение данных
- **API** — интерфейс взаимодействия

#### Инфраструктура:
- **Веб-сервер** (Nginx, Apache)
- **DNS** — система доменных имён
- **CDN** — сеть доставки контента
- **Load Balancer** — распределение нагрузки

### Модели развёртывания:
1. **Monolithic** — единое приложение
2. **Microservices** — набор независимых сервисов
3. **Serverless** — функции как сервис (FaaS)
4. **Hybrid** — комбинированный подход

---

## 4. Типы интернет-приложений

### По назначению:
- **SaaS** (Software as a Service) — программное обеспечение как услуга
- **E-commerce** — электронная коммерция
- **Social Networks** — социальные сети
- **Content Management** — управление контентом
- **Communication** — коммуникационные платформы
- **Educational** — образовательные платформы
- **Entertainment** — развлекательные сервисы
- **Productivity** — инструменты продуктивности
- **Analytics** — аналитические системы
- **IoT Platforms** — платформы интернета вещей

### По архитектуре:
- **Single Page Application (SPA)** — одностраничное приложение
- **Progressive Web App (PWA)** — прогрессивное веб-приложение
- **Multi-Page Application (MPA)** — многостраничное приложение
- **Isomorphic/Universal App** — изоморфное приложение

---

## 5. Эволюция веб-приложений

### Поколения:
1. **Web 1.0** (1990-е) — статические страницы
2. **Web 2.0** (2000-е) — интерактивные приложения, user-generated content
3. **Web 3.0** (2010-е) — семантический веб, AI, персонализация
4. **Web 4.0** (2020-е) — децентрализация, blockchain, метавселенные

### Современные тренды:
- **JAMstack** — JavaScript, APIs, Markup
- **Edge Computing** — вычисления на границе сети
- **WebAssembly** — бинарный формат для веба
- **Real-time Applications** — приложения реального времени
- **AI Integration** — интеграция искусственного интеллекта
